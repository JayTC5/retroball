# Retroball Club

A single-player retro baseball card game built with HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser, or use GitHub Pages to publish the repository.

## Features

- Three tiers of player packs
- Common, rare, epic, and legendary players
- Power, contact, and speed attributes
- Roster and team-overall view
- Animated at-bat baseball minigame
- Coins earned from hits and completed innings
